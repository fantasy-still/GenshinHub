# 原神百科 · GenshinHub

原神世界观与剧情问答客户端。用自己的话梳理人物经历、势力关系、故事因果与历史时间线，并提供可点击的本地原文出处。

**快速开始：下载 Windows 成品 ZIP → 完整解压 → 双击“启动原神百科.cmd” → 填写自己的 DeepSeek API Key → 开始提问。**

当前免安装版适用于 **Windows 10/11 x64**，包含运行环境、资料和检索缓存，无需安装 Python、下载模型或配置环境变量。离线可以搜索本地资料；生成回答需要联网，API 费用由你的 DeepSeek 账户承担。

## 1. 下载与启动

1. 在项目 GitHub 的 **Releases** 页面下载名称含 `windows-x64` 的成品 ZIP，例如 `GenshinHub-0.1.2-windows-x64.zip`。普通使用者选择这个包；页面上的 `Source code` 是供开发者使用的源码。
2. 右键 ZIP，选择“全部提取”，或用解压软件完整解压到一个普通文件夹。
3. 打开解压后的文件夹，双击 **启动原神百科.cmd**。出现启动提示后，稍候即可打开聊天界面。
4. 首次使用会打开“连接与偏好”。按下一节申领密钥，再完成连接。

请把 `GenshinHub.exe`、`data`、`_internal` 和启动脚本放在一起，不要只复制 EXE，也不要直接在压缩软件内运行。`Readme.md` 是本使用指南，“第三方许可”目录包含依赖软件的许可说明。

程序优先打开桌面窗口；如果电脑的 WebView2 不可用，会尝试通过系统默认浏览器打开同一界面。浏览器模式需保留启动窗口，结束后在启动窗口按 **Ctrl+C** 停止服务。也可以在解压目录打开终端，运行：

```bat
启动原神百科.cmd --browser
```

## 2. 申领 DeepSeek API Key

API Key 是让本软件使用你的 DeepSeek 账户调用模型的访问密钥。请在官方开放平台创建。[DeepSeek 官方 API 介绍与申领入口](https://www.deepseek.com/platform/)

### 注册、创建与充值

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，按页面提供的方式注册或登录。
2. 进入 **API keys / API 密钥** 管理页，也可以直接访问 [API Key 管理入口](https://platform.deepseek.com/api_keys)。未登录时先完成登录。
3. 找到创建密钥的按钮，给这把密钥起一个便于辨认的名字，例如“原神百科”，然后创建。
4. 创建后立即复制完整密钥并妥善保存。若之后无法查看完整内容，可以重新创建，再替换软件里的密钥。
5. 在开放平台查看账户余额和充值入口；如果余额不足，按官方页面提示完成充值。平台要求认证时按提示办理。有没有赠送额度、支持哪些支付方式，以你当前账户显示为准。
6. 回到原神百科，粘贴密钥并连接。无需把密钥写进本项目文件，也不需要配置环境变量。

官方平台的菜单名称可能调整，以上按“登录 → API 密钥 → 创建 → 复制 → 检查余额”的顺序操作即可。充值、账户与密钥问题可查阅 [DeepSeek 官方帮助中心](https://api-docs.deepseek.com/zh-cn/faq/)。

### 费用与密钥保存

DeepSeek API 按 Token 用量计费，具体单价与优惠以 [官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 为准。较长的问题、历史对话、检索片段和模型输出都会影响用量；开启专业复核会增加请求。软件不承诺固定“每道题价格”或免费额度。

默认只在本次运行使用密钥；勾选“记住密钥，保存到系统凭据存储”后，保存到这台电脑的 Windows 凭据管理器。不要把密钥发给他人、贴进聊天问题或提交到 GitHub。怀疑泄露时，应到官方密钥管理页删除旧密钥并创建新的，再更新软件中的连接。

## 3. 首次连接软件

1. 在“连接与偏好”中找到 **DeepSeek API Key**，粘贴完整密钥，避免多余空格。
2. 自用电脑可以按需要勾选“记住密钥”；临时或共用电脑保持不勾选。
3. 点击 **验证并连接**。显示“已连接，可开始对话”后，点击设置窗口右上角 **×** 返回聊天。
4. 保留默认模型 `deepseek-flash`，即可开始使用。其实际版本由 DeepSeek 官方维护。

以后可点击左下角 **本地工作空间**，或顶部模型名称，再次打开“连接与偏好”。如果软件已读取系统凭据或你自己配置的 `DEEPSEEK_API_KEY` 环境变量，会显示已配置状态。

“验证并连接”主要核验密钥和可用模型；验证成功后若回答提示余额不足，仍需到开放平台检查余额。

## 4. 提问、追问与阅读回答

### 开始一段对话

1. 点击左侧 **新的对话**，或按 **Ctrl+N**。
2. 在底部输入问题，按 **Enter** 发送；按 **Shift+Enter** 换行。也可以点击右下角发送按钮。
3. 等待模型查询资料并回答。界面会显示检索、原文回查和回答生成状态。
4. 回答结束后直接继续提问，同一对话会沿用前面的完整历史。切换到另一主题时可以新建对话。

可以先试这些问题：

- 丑角和海洛塔帝在坎瑞亚分别担任过什么职务？他们的关系怎样影响后来的选择？
- 枫丹预言是如何被化解的？请区分芙宁娜、芙卡洛斯和那维莱特各自的作用。
- 请按因果梳理水仙十字的故事，区分阿兰、雷内、雅各布和玛丽安的不同选择。
- 散兵删除世界树中的记录之后，丹羽是否复活？请区分历史事件与记忆变化。

问题越具体，越容易得到完整且相关的回答。可以补充国家、任务、人名或希望的结构，例如“先给结论，再解释前因后果，最后列出处”。

### 查看思考与出处

- **DeepSeek 的思考**：模型返回思考内容时会显示该区域，生成过程中自动展开，可以手动折叠；历史回答中也能点击展开。关闭思考或接口未返回该字段时，不会凭空生成思考记录。
- **原文出处**：点击回答中的资料引用，在右侧查看文件名称、行号和正文；用“上一段 / 下一段”查看更多上下文。
- **复制回答**：点击回答下方对应按钮。
- **停止回答**：生成时点击输入框右下角的停止按钮。已经收到的内容会保留，之后可以继续提问。

引用能够定位文件与行号，并不自动证明推断正确。重要剧情结论建议打开原文核对，留意角色说法、维基分析与游戏事件的区别。

### 搜索本地资料

点击左侧 **搜索资料**，输入人名、别名、任务或事件关键词，查看结果并打开原文。搜索不调用 DeepSeek，不消耗模型 Token；离线也可使用。未配置密钥时，可以先关闭连接窗口再进入搜索。

## 5. 管理历史、导出与记忆

| 想做什么 | 操作方法 |
| --- | --- |
| 继续以前的对话 | 点击左侧对话标题，重启软件后历史仍保留在本机 |
| 查找某段对话 | 在“搜索对话…”框输入标题关键词 |
| 重命名 | 点击对话右侧的铅笔图标，填写标题并保存 |
| 删除对话 | 点击对话右侧的 ×，确认删除；生成中请先停止 |
| 导出当前对话 | 点击顶部“导出对话”图标，保存为 JSON；包含完整消息和工具结果，无导入恢复功能 |
| 查看上下文与用量 | 点击顶部“上下文信息”图标；用量来自最近一次 API 请求，不是下一次费用的精确估算 |
| 保存跨对话偏好 | 点击“我的记忆”，填写偏好并点击“保存记忆” |
| 删除某条偏好 | 在“我的记忆”中点击该条记录的“删除” |

记忆适合保存“先给简短结论”“重点关注坎瑞亚人物”等阅读偏好，需要你主动保存。它不会改写知识库，也不会作为剧情证据。删除一段对话不会同时删除已保存记忆。

会话、设置和记忆位于：

```text
%LOCALAPPDATA%\TeyvatArchive
```

可将这一地址粘贴到 Windows 文件资源管理器的地址栏打开。备份时先关闭软件，再复制该目录；其中包含你的私人对话，分享软件时不要把它一起打包。保存到 Windows 凭据管理器的密钥不在该目录内。

该目录沿用早期版本的内部名称，以便更名后继续读取已有历史；应用显示名称已改为“原神百科”。

## 6. 模型设置与专业复核

在“连接与偏好”里调整设置后，点击 **保存偏好**，下次请求生效。初次使用保留默认值即可。

| 设置 | 用途 |
| --- | --- |
| 模型名 | 默认 `deepseek-flash`；“刷新可用模型”查看账户实际可用的模型 |
| 思考强度 | 默认遵循 API 设置，也可选择关闭、低、高或最高 |
| 输出 Token 上限 | 留空使用 API 默认；手动填写会限制单次生成长度 |
| 专业复核 | 默认关闭；启用后对初稿进行独立证据审阅并修订，增加等待时间和 API 费用 |
| 每次回答最多查询轮数 | 默认32轮，限制一次回答连续查询资料的次数 |

专业复核开启后，可以展开查看保留的初稿与审阅记录；同一模型自查仍可能有误，不能代替原文核对。

软件保留并回传完整历史，不自动摘要或裁剪。很长的对话会增加用量；达到官方上下文限制时会提示错误，可新建对话继续。达到单次输出或查询轮数限制时，已收到的内容和工具上下文会保留。

需要比较同一模型的直接回答时，在设置中点击 **新建原生对话**。该模式不附加本地知识库、用户记忆或本软件的系统提示，适合进行 API 对照；研究剧情一般使用默认的知识库对话。

## 7. 更换密钥与退出

更换密钥：打开“连接与偏好”，输入新的密钥并点击“验证并连接”。清除密钥：先停止正在生成的回答，再点击 **清除密钥** 并确认。此操作清除本次运行及本应用保存的系统凭据，对话历史会保留。

如果你自行配置过 `DEEPSEEK_API_KEY` 环境变量，软件内的“清除密钥”不会删除该变量，重启后会再次读取；要停止自动加载，需要另外移除自己设置的环境变量并重启相关应用。

桌面模式关闭软件窗口即可结束；浏览器模式需在启动窗口按 **Ctrl+C**。更换程序版本时先退出软件，再解压新版本；使用同一 Windows 用户时，本地历史和记忆仍从用户数据目录读取。

## 8. 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 双击后没有聊天窗口 | 确认已完整解压，启动脚本、EXE、data、_internal仍在一起；查看启动窗口中的错误。可尝试浏览器模式 |
| 提示已经在运行 | 切换到已有客户端窗口；退出旧客户端后再打开 |
| 密钥无效或连接失败 | 从官方平台重新复制密钥，检查网络和账户可用模型；不要用第三方中转平台的密钥代替 |
| 验证成功但回答提示余额不足 | 在 DeepSeek 开放平台检查余额并按提示充值 |
| 等待时间较长 | 长问题、资料回查、模型思考和专业复核都可能增加耗时；可停止回答，缩小问题范围，或关闭专业复核 |
| 没有显示思考内容 | 检查是否关闭了思考；只有接口实际返回思考字段时才会显示 |
| 某段最新剧情找不到 | 本包资料不会随游戏更新自动增长；用任务名、别名再次搜索，并留意软件说明的资料截止范围 |
| 资料或缓存校验失败 | 重新下载并完整解压匹配版本，不要混用不同版本的data和_internal |

## 9. 资料范围与数据去向

本版本冻结清单日期为 **2026-10-13**，基准采集为 **2026-10-05**，含 **2026-10-09** 增量；资料覆盖空月之歌及第七章7.1相关来源。增量收录不等于每份归纳稿都已吸收所有更新，维基考据也不等于官方事实。

问题、当前对话、必要的检索片段和启用的记忆会随请求直达 DeepSeek 官方接口；整个知识库不会一次性上传。会话保存在使用者电脑，发布包不附带开发者或其他使用者的会话、记忆、配置与 API Key。

本软件是非官方剧情阅读与检索工具，剧情文本、原神相关名称及维基内容等权利归各自权利人，资料保留原有来源。依赖许可见“第三方许可”目录。当前程序未做商业代码签名，可用配套 SHA-256 文件核对下载完整性。
