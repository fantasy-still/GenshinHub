# GenshinHub 源码开发说明

普通使用者下载Release中的Windows成品即可。源码仓库提供Python后端、桌面宿主、前端、测试及打包配方。剧情资料和超过普通Git文件限制的SQLite索引随Release成品提供，没有放入这份源码上传文件夹。

## 还原开发资料

1. 下载匹配的`GenshinHub-0.1.2-windows-x64.zip`并完整解压。
2. 将成品中`data`目录的**内部内容**复制到源码仓库根目录；不要再套一层data。根目录应出现10—90编号资料目录、update_20261009，以及99目录下必要的检索脚本。
3. 数据对应`app/knowledge.lock.json`，保留原文及原索引，只读使用。

开发环境使用Python 3.12。在仓库根目录打开终端：

```powershell
cd app
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -m twwiki.freeze verify
.venv\Scripts\python.exe -m twwiki
```

单独运行程序时也可用`TEYVAT_CORPUS`指定另一份完整资料根目录，用`TEYVAT_USER_DATA`指定独立的可写用户目录；不需要把真实API Key写进源码。

## 测试与构建

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m pip install -r packaging/requirements-build.txt
.venv\Scripts\python.exe packaging/build_release.py
```

构建在Windows x64进行，默认输出到仓库根目录releases。已有同名输出时使用新的`--output`路径。自动测试不调用真实计费模型，live_check.py和quality_check.py属于维护者主动执行的真实接口检查，可能计费。

源码运行的会话与设置位于`app/.local`，成品运行位于Windows本地应用数据目录，均被排除在源码和发布输入之外。可见剧情文本、维基整理与第三方依赖保留各自来源和权利信息；本次准备上传文件尚未为应用代码指定开源许可证。
